## 🌾 لعبة المزرعة - Farm Game

لعبة محاكاة مزرعة تفاعلية مع نظام زراعة وتربية الحيوانات والتجارة!

### ✨ الميزات

#### 🌱 نظام الزراعة
- **4 أنواع محاصيل:**
  - 🌾 قمح (50💰) → 150💰
  - 🌽 ذرة (75💰) → 200💰
  - 🍅 طماطم (60💰) → 180💰
  - 🥕 جزر (55💰) → 160💰

- نظام نمو تدريجي (3-4 أيام للنضج)
- حصاد يدوي أو حصاد جماعي
- نظام مخزن للمحاصيل

#### 🐄 نظام تربية الحيوانات
- **4 أنواع حيوانات:**
  - 🐄 بقرة (200💰) - إنتاج 100 يومياً
  - 🐔 دجاجة (100💰) - إنتاج 50 يومياً
  - 🐷 خنزير (150💰) - إنتاج 80 يومياً
  - 🐑 خروف (120💰) - إنتاج 60 يومياً

- إطعام الحيوانات (20💰 للحيوان)
- إنتاج يومي تلقائي
- نظام إدارة المخزون

#### 🏪 نظام التجارة
- بيع المحاصيل في السوق
- أسعار ثابتة:
  - 🌾 قمح: 100💰
  - 🌽 ذرة: 150💰
  - 🍅 طماطم: 120💰
  - 🥕 جزر: 110💰

#### 🌤️ نظام الطقس
- تغيير الطقس عشوائي كل يوم
- أنواع: مشمس ☀️، ممطر 🌧️، غائم ☁️

#### ⭐ نظام المستويات
- رفع المستوى كل 10 محاصيل مجموعة
- مكافأة 500💰 عند الترقية
- تتبع الإحصائيات العامة

#### ⏰ نظام اليوم
- يوم لعبة كامل مع ساعات
- تقدم تلقائي للمحاصيل
- إنتاج الحيوانات كل يوم

### 🎮 كيفية اللعب

1. **ابدأ مع 1000💰**
2. **اختر محصول وازرعه** في الحقل
3. **انتظر النضج** (شاهد تغيير الرموز التعبيرية)
4. **اجمع المحاصيل** عند نضجها
5. **اشتري حيوانات** لتحقيق دخل منتظم
6. **بيع المحاصيل** في السوق
7. **رقِّ المستوى** بجمع المزيد من المحاصيل

### 🎯 الهدف

- جمع أكبر عدد من المحاصيل
- بناء مزرعة مربحة
- الوصول لأعلى مستوى
- تحقيق أقصى دخل

### 📊 تتبع الإحصائيات

- **المال الحالي** - متوسط ما لديك الآن
- **المستوى** - درجة التقدم
- **اليوم والوقت** - تقدم اللعبة الزمني
- **الطقس** - تأثير بيئي
- **الإحصائيات:**
  - إجمالي المحاصيل المجموعة
  - إجمالي المال المكتسب
  - المال الحالي

### 🔄 الإجراءات الرئيسية

| الإجراء | الوصف |
|--------|-------|
| زراعة المحاصيل | اختر نوع محصول وازرعه |
| شراء حيوانات | استثمر في الحيوانات للدخل |
| إطعام الحيوانات | حافظ على صحة حيواناتك |
| اليوم التالي | تقدم اليوم والحصول على الدخل |
| حصاد الكل | اجمع جميع المحاصيل الجاهزة |
| فتح السوق | بيع المحاصيل للحصول على المال |
| إعادة تعيين | ابدأ لعبة جديدة |

  - متجر للترقيات
  - تحديات يومية
  - نظام الإنجازات

### 🎮 نصائح للعب الأفضل

1. **في البداية:** ركز على المحاصيل السريعة (قمح، جزر)
2. **في المراحل المتوسطة:** استثمر في الحيوانات
3. **في المراحل المتقدمة:** وازن بين المحاصيل والحيوانات
4. **الدخل الثابت:** الحيوانات تعطيك دخل يومي مستقر
5. **الدخل المتغير:** المحاصيل تعطيك دخل أعلى لكن أقل استقراراً
